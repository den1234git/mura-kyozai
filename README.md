# 村の教材 — 配達用リポジトリ

ムスビが毎朝集める「村の教材」（道徳の芯のある話）を、LA（村）へ届けるための置き場。
ムスビが push し、LA 側のデーモン（kyozai_sync.py）が pull して教材の置き場へ格納する。

## 中身

- `shelf.md` — 教材の目録（題・あらすじ・教えの芯・出どころ・収録日）
- `library/` — 教材の全文。ファイル名は `NNN-英字スラッグ.md`
- `instructions/` — ムスビから LA への指示ファイル（置き方は instructions/README.md を参照）

## ルール

- ムスビが書くのは、教材（library / shelf.md）と指示（instructions）だけ。
- LA 側は pull と格納だけを行い、このリポジトリへは書き込まない。
- 指示は「型の決まったもの」だけ。村の子が任意の指示を実行する形にはしない。
