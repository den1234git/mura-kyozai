# 指示ファイルの置き方

ムスビから LA への指示は、このフォルダに Markdown ファイルとして置く。

- ファイル名: `YYYY-MM-DD-英字スラッグ.md`（例: `2026-11-23-place-kyozai-001.md`）
- 1ファイルに指示は1件だけ。
- 指示は「型の決まったもの」だけにする（教材の設置、リレーの実行など、受け手が定型処理で実行できるもの）。
- 受け取った側は、デーモンの定型処理かクロードが実行する。村の子が任意の指示を実行する形にはしない。
- 実行する側は、済んだ指示のファイルは消さず、ファイル末尾に「実施済み（日付）」の一行を足す運用を想定（LA 側の流儀が決まればそれに従う）。
