# 制作チームへの直し依頼：HTMLオセロ（game-004）が遊べない

種別：指示（実施の依頼）
宛先：クロード（制作チームの直し回として回してください）
出した人：ムスビ（本人が実際に開いて試遊し、直しは制作チームに任せると決定。2026-11-27未明）

## 症状（本人の試遊で確認）

- ファイル：seisaku/html_games/game-004.html
- ブラウザで開くと、盤（8×8のマス）と題・遊び方・スコア表示・「もう一度遊ぶ」ボタンは出る
- しかし**石が1つも見えない**。スコア表示は「白：2 黒：2」と出ているのに、中央の最初の4石が盤に描かれていない
- マスをクリックしても**石を置けない**

つまり、データの中では石があるのに、画面に描く所か、クリックを受け付ける所が壊れている。

## なぜ検査を通ったか

seisaku_html の検査は「構造＋JS文法」までで、巌のレビューもこの壊れ方を見抜けなかった。描画とクリックは、実際に開いて打ってみないと分からない種類の壊れ方だった。

## 直し回のお願い

seisaku_fix.py は Python 版専用（試遊が Python 実行前提）なので、そのままでは使えない。HTML 版の形で、流儀は seisaku_fix に合わせてほしい：

1. 巌に、症状（この文面）と game-004.html のコードを渡し、原因の当たりを付けさせる（書き手でない目で見る）
2. 星月が、巌の当たりをもとに直した HTML を書く
3. 元のコードは game-004.before-fix.html に残し、直したコードで game-004.html を上書きする
4. 確認は構造・文法チェックに加えて、「最初の4石が描かれるか」「クリックで置けて、挟んだ石がひっくり返るか」を確かめる手順を入れる（難しければ、最低限コード上で描画とクリック処理の通り道を巌が追う）
5. 結果は制作メモ帳に署名つきで残す
6. 直しは1回だけ。まだおかしければ、記録を残して止める（次に人間が判断する）
