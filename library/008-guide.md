# 読み助け — 教材008『まっすぐな青年』

## 登場人物

- **私（語り手）** — 団地に住む会社員。夜、会社から帰る途中で青年を見つける。
- **青年** — 14から16歳の男の子。雨の中、向かいの団地を見ながら立ち続けている。
- **団地友達** — 向かいの団地に住む私の知り合い。
- **娘さん** — 団地友達の娘。16歳で急性白血病で亡くなった。

## 場面の順番

1. 夜8時、雨の中、公園で向かいの団地を見ながら立つ青年を私が見つける場面
2. 1時間後もまだ立っているのを見て、警察を呼ぶか迷う場面
3. 翌朝、窓から見るとまだ立っている場面
4. 私が傘を渡して声をかけるが、青年は「ありがとうございます」とだけ答える場面
5. さらに6時間立ち続け、私が向かいの団地の知り合いに電話して調べる場面
6. 青年が亡くなった娘の彼氏だったと分かる場面

## 時間の流れ

話は20年前の3月初め。夜8時に私が青年を見つけ、1時間後もまだいた。朝になって、私が見てから10時間ほど経っていた。さらに6時間、青年は立ち続けた。娘さんが亡くなったのは、その1ヶ月前。

## 難しい言葉

- **団地（だんち）** — 同じような建物が並んだ集合住宅
- **急性白血病（きゅうせいはっけつびょう）** — 血液の癌の一種
- **線香（せんこう）** — 仏壇や墓でたく香り。亡くなった人を弔うときにあげるもの
- **微動だにしない** — ほんの少しも動かない
- **不良ぶっている** — わるぶっている。素行が悪いふりをしている
- **脳裏に焼き付いている** — 頭の中に強く残っていて、忘れられないこと
