# 読み助け — 教材004『うつ病だった俺がようやく回復したのだが』

## 登場人物

- **俺（語り手）** — 現在26歳。高校で息苦しさを感じて中退し、5年間引きこもっていた。話の終わりではアルバイトを始めている。
- **母さん** — 俺の母親。引きこもっている俺の部屋の前に、毎年誕生日にチョコレートケーキを置いてくれる。
- **おじいさん（会長）** — 70代くらい。近所の海で毎晩夜釣りをしている。地元で一番成功していると言われる企業の会長。
- **会長の友達** — お母さんが建てたマンションの収入で暮らしているが、働きたいと思っている人。会長の話の中に出てくる。
- **上司** — 俺がアルバイトを始めた職場の上司。話の終わりに少しだけ出てくる。

## 場面の順番

1. 高校で息苦しさを感じ、病院でうつの診断を受け、引きこもりになる場面
2. 5年間、部屋の前に母が毎年誕生日ケーキを置いてくれる場面
3. ロウソクが5本になった誕生日に涙し、部屋を出て、部屋の鍵を壊す場面
4. 近所の海で夜釣りを始め、70代のおじいさんと出会う場面
5. 毎晩の夜釣りで、おじいさんと話を続ける場面
6. 酒に酔って釣りをした翌日、クーラーボックスの横に浮輪が置かれている場面
7. 今年からアルバイトを始め、おじいさんが職場に遊びに来てくれる場面

## 時間の流れ

高校時代の息苦しさから始まり、5年の引きこもりを経て、部屋を出て夜釣りを始めた日々、そして今年アルバイトを始めるところまで進む。話の始まりから終わりまで、何年もの時間が経っている。

## 難しい言葉

- **うつ病（うつびょう）** — 気分が沈み、体が動かなくなるなどの症状が続く病気
- **引きこもり（ひきこもり）** — 部屋から出ず、外の人と会わない生活が長く続くこと
- **中退（ちゅうたい）** — 学校を卒業せずに途中でやめること
- **死刑宣告（しけいせんこく）** — 死刑を言い渡されること。ここでは朝のアラームの苦しさをたとえている
- **ロウソク** — 誕生日ケーキに立てる、火をつける細いろうの棒
- **夜釣り（よづり）** — 夜に海などで魚を釣ること
- **釣り糸（つりいと）** — 釣り竿の先につけて、針と餌をつなぐ糸
- **仕掛け（しかけ）** — 魚を釣るための針やおもりなどの道具の組み合わせ
- **社交辞令（しゃこうじれい）** — 相手に断ったりする時に使う、決まった丁寧な言い回し
- **笑いじわ** — 笑う時にできる、顔のしわ
- **一頻り（ひとしきり）** — 一通り、しばらくの間
- **クーラーボックス** — 釣った魚や飲み物を冷たく保つ箱
- **浮輪（うきわ）** — 水に浮く輪。海で溺れないための道具
- **クズ** — くだらない人間、という自分をけなす言葉
- **アルバイト** — 短い時間で働く仕事
