# 消防チームの棚

消防チーム（銀風＋神楽）のお題と採点結果を、ここに全部集める。確認はこのフォルダだけ見れば済む形。

- `odai-NNN.md`：ムスビが出したお題（LAへ届いて、チームが解く）
- `kekka-NNN.md`：ムスビの採点結果（捕捉・見落とし・誤検出と、次のお題への反映）
- 答え合わせの鍵はここには置かない（ムスビの手元だけに保管）。

村側の作業場は LA の `shobo\` フォルダ（メモ帳 shobo_memo.md）。結果は la_deliver で la-reports の reports/shobo_team/ へ届き、ムスビが採点して、ここに kekka として返す。
